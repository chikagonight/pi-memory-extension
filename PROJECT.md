# pi-memory-extension

## Цель

Минимальное собственное расширение pi для персистентной памяти фактов/решений между сессиями — замена небезопасному готовому пакету `pi-mem` (см. раздел 1 `TZ.md` — список обнаруженных уязвимостей).

Полная спецификация: [`TZ.md`](./TZ.md).

## Ключевые решения (зафиксированы с пользователем)

- Сохранение: ручное (`memory_save` tool) + автоматическое извлечение на `session_before_compact`.
- Подгрузка в сессию — только по явному tool-вызову, без авто-инъекции в промпт.
- Область памяти — глобальная (project — тег для удобства, не граница безопасности).
- Поиск — keyword (FTS5) обязателен; semantic — опционально, через собственный embeddings-provider на `ollama-home`.
- Хранилище: SQLite (`better-sqlite3`), только parameterized-запросы.
- Приватность: тег `<private>` + regex-эвристики на секреты, применяются к input/output/prompt.

## Критерии приёмки (см. раздел 7 TZ.md)

- Тесты из раздела 6.1 TZ.md проходят.
- `reviewer` дал вердикт ✅ отдельно по функциональности и по безопасности.
- `/memory` показывает корректный статус; `memory_save` → `memory_search` в новой сессии находит запись.
- Секрет без `<private>`, но попадающий под regex-паттерн, не сохраняется в открытом виде.
- Ничего не попадает в промпт без явного tool-вызова.
